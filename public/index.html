Features

What Trader does, in one screen per concern.

Seven focused sub-pages replace the single 14-card dashboard. Each one answers exactly one question — stage, PnL, positions, trades, models, cadence, dev — so you stop scrolling and start operating.

📡

Live Kalshi feed

Alarm-driven REST polling on a 1.5s round-robin over a single Durable Object. Orderbook, fills, and signals — pushed through one edge connection.

🛡

Per-vertical risk caps

Hard limits per fill, per day, and per vertical (weather, economic, politics, sports). The bot refuses every trade that would push it over either cap, regardless of model confidence.

💵

Paper or real, on the flip

Default paper. One click + a confirmation modal to flip to real money. Kill switch panic-stops in one click. Caps, position sizing, and per-vertical overrides all stay in force.

⏱

Automated cadence

Scan every 15 min · news every 6h · daily recap 06:00 UTC · weekly retrain. Plus an LLM-powered daily digest to your inbox or Telegram.

🧠

Per-vertical ML models

Reversions on weather + economic, naive baseline on politics + sports. Model registry in R2; promote / retire / retrain via a single API call.

📊

Cost-aware

CF Workers free tier covers it; only the LLM is a real cost. Live 24h + monthly projection, right on the dashboard.

How it works

From the WS to the fill, in three steps.

Every cycle, end-to-end. The same loop runs in paper and real mode — only the order placement changes.

1

Stream the orderbook

The Durable Object wakes every 1.5s and pulls the latest orderbook for every active vertical. No missed ticks, no orphaned WebSockets.

2

Score with the model

The per-vertical model returns a probability. Signals that pass the min-confidence + per-vertical caps become intents.

3

Fill (paper or real)

Intents get a price-cents + size, then a fill — simulated against the live mid (paper) or placed on Kalshi (real). The whole loop takes <2s.
