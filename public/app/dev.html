Manual actions
Side-effects that need a click. Each one fires a POST and shows the result in a toast. Use carefully — go-live places real orders, close-position exits at the current mark.
⏱ Manual cron triggers runs the cron on demand · records to cron_runs
The crons run on a CF schedule (every 15min / 6h / daily / weekly). Hit a button to run one now without waiting. The news-cron can send a Telegram if it detects an at-risk position; daily-cron posts the recap to Telegram.
🎯 Lead suggestions never run
LLM-driven add + drop suggestions for the bot's ticker universe. The leads-cron runs daily 02:00 UTC. Each pending card is one LLM suggestion with reasoning. Approve to apply (bot restarts); reject so the LLM won't re-suggest this ticker for 30 days. Undecided cards are quietly replaced on the next run.

API endpoints
Every endpoint exposed by the Worker. Read-only endpoints auto-refresh; write endpoints are above. Click a path to copy it.
GET /api/pm/status Worker health (DB, R2, DO, asset binding)
GET /api/pm/summary Aggregate dashboard summary (counts, PnL, recap)
GET /api/pm/bot/status Live bot DO state (stage, config, risk)
GET /api/pm/bot/stage Just the stage panel data (fast)
GET /api/pm/bot/balance Live Kalshi account balance
GET /api/pm/trades Recent trades (paginated, ?limit=N)
GET /api/pm/signals Recent signals (paginated, ?limit=N)
GET /api/pm/scans Latest scan results
GET /api/pm/cron-runs Latest cron run results (last 10)
GET /api/pm/cadence Cadence panel (cron + model + WS + LLM)
GET /api/pm/cf-analytics CF Workers analytics (last 24h)
GET /api/pm/cost Cost estimate + monthly limits
GET /api/pm/verticals Per-vertical PnL + open positions
GET /api/pm/models List all models in registry
GET /api/pm/models/active Active model per vertical
POST /api/pm/bot/start Start the live bot
POST /api/pm/bot/stop Stop the live bot (WS disconnects)
POST /api/pm/bot/restart Restart the live bot
POST /api/pm/bot/reload-models Reload model registry from R2
POST /api/pm/bot/trading-mode Set trading mode (paper/real/off)
POST /api/pm/bot/kill-switch Toggle kill switch
POST /api/pm/bot/place-test-order Place a manual order (real money)
POST /api/pm/bot/close-position Close an open position at current mark
POST /api/pm/bot/cancel-order Cancel a pending GTC order
POST /api/pm/bot/auto-start Idempotent start (no-op if already running)
POST /api/pm/bot/telegram-test Send a test Telegram message
POST /api/pm/bot/llm-test Test the configured LLM (MiniMax-M3) end-to-end
POST /api/pm/bot/suggest-leads LLM-powered lead generation: asks M3 for new Kalshi tickers to add (body: {count?, exclude?, current_tickers?, verticals?, bankroll_cents?})
GET /api/pm/leads List pending + historical lead suggestions (the leads-cron pipeline)
POST /api/pm/leads/{id}/approve Approve a pending lead suggestion. Applies to bot's universe + restarts.
POST /api/pm/leads/{id}/reject Reject a pending lead suggestion. Cron won't re-suggest this ticker for 30 days.
POST /api/pm/bot/smoke-test E2E smoke test: LLM + Telegram + every cron + cadence panel
GET /api/pm/cron List triggerable crons (one entry per cron in the schedule)
POST /api/pm/cron/{name}/run Trigger a cron on demand (scan, news, daily, train, auto_pilot, backtest)
POST /api/pm/models/register Register a new model version
POST /api/pm/models/promote Promote a model to active
POST /api/pm/models/retire Retire a model from active
POST /api/pm/backtest/run Run a backtest with current config
