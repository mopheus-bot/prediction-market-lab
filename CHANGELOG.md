# Changelog

Every notable change to the Prediction Market Lab Worker, in the order it landed.

The service was built in a single five-day sprint (2026-08-08 → 2026-08-12) and
has been maintained since. Per-feature engineering notes — what shipped, which
schema migration it needed, and how it was verified — live in
[`docs/changelog/`](docs/changelog/README.md).
